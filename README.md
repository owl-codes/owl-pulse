# 🚀 CryptoPulse

Live crypto price tracker with portfolio management.

## Features
- Real-time prices for BTC, ETH, SOL, DOGE, XRP, EDU + more
- 7-day sparkline charts
- Portfolio tracker (local storage - private per device)
- Auto-refresh every 30 seconds

## Live Demo
https://crypto-live-feed--owlcod3s.replit.app

## Built With
- TypeScript / React
- Express.js
- CoinGecko API
- Tailwind CSS
