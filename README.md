# OwlPulse

Live crypto price tracker with portfolio management.

## Live Site

https://owl-pulse.netlify.app

## Features

- **Real-time prices** — BTC, ETH, SOL, DOGE, XRP + any token from CoinGecko
- **Add any token** — search CoinGecko's full catalog and add to your dashboard
- **7-day sparkline charts** — inline price history on every card
- **Price alerts** — set target prices and get browser notifications when they hit
- **Favorites** — pin tokens to the top of the grid with a star
- **Drag to reorder** — rearrange your token cards by dragging
- **Portfolio tracker** — track holdings and total balance (localStorage, private per device)
- **Auto-refresh** — prices update every 30 seconds

## Tech Stack

- TypeScript / React
- Vite
- Framer Motion (animations + drag-and-drop)
- Tailwind CSS
- CoinGecko API
- Netlify Functions (serverless API)
